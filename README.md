<h1 align="center">Ключница</h1>

<p align="center"><b>Локальный менеджер паролей для Windows.</b><br>

## Зачем

Браузерные менеджеры паролей удобны, но пароли живут на серверах компании. Ключница делает наоборот: один файл `*.klv`, зашифрованный мастер-паролем, лежит там, где вы скажете, и никуда не отправляется. Перенести пароли из Яндекс Браузера или Chrome — одна минута.

## Что умеет

- **Импорт** из Яндекс Браузера, Chrome / Google Password Manager, Microsoft Edge, Firefox, Bitwarden, KeePass. Предпросмотр, подсветка дублей, CSV после импорта затирается.
- **Поиск** по сайту, логину и тегам-«крючкам», избранное, заметки, подсказка «пароль старше года».
- **Генератор** паролей с оценкой стойкости.
- **Аккуратно с секретами:** пароль показывается только пока удерживаете кнопку, копирование в буфер с автоочисткой через 20 секунд, автоблокировка по таймеру, нарастающая задержка при неверном мастер-пароле.
- **Светлая и тёмная темы**, горячие клавиши `Ctrl+F` / `Ctrl+N` / `Ctrl+L`.
- Установщик ~10 МБ, без телеметрии и без интернета.

**Скоро:** браузерное расширение «Сохранить в Ключницу?» (перехватывает регистрацию на сайтах), второй фактор — код от Telegram-бота, аппаратный FIDO2-ключ.

## Как получить

Цена — пожертвование, сколько считаете справедливым (от 100 ₽). Так это работает:

1. Переведите донат: **[tips.tips/000488835](https://tips.tips/000488835)** (банковская карта, без регистрации).
2. Напишите на **neurocreator24@gmail.com** со скриншотом или номером перевода.
3. В ответ придёт установщик `Klyuchnitsa_x.y.z_x64-setup.exe`. Обновления 0.x — бесплатно, тем же письмом по запросу.

Контрольные суммы SHA-256 всех установщиков публикуются в [Releases](../../releases) этого репозитория — сверьте после получения файла.

Требования: Windows 10/11 x64, WebView2 (в Windows 11 уже есть).

## Безопасность

- Мастер-пароль → **Argon2id** (64 МиБ памяти, 3 итерации) → ключ шифрования.
- Тело файла шифруется **XChaCha20-Poly1305**; открытый заголовок файла привязан к шифротексту, поэтому подмена параметров обнаруживается.
- Ключи обнуляются в памяти после использования; файл пишется атомарно, предыдущая версия хранится в `*.klv.bak`.
- Исходный код закрыт. Честно о том, что это значит: вы доверяете автору, как доверяете любой программе без кода. Что можно проверить самостоятельно: программа не создаёт сетевых соединений (проверьте в брандмауэре), файл хранилища не читается без мастер-пароля, контрольные суммы установщиков совпадают с опубликованными.
- От чего **не** защищает ни один локальный менеджер: от кейлоггера на уже заражённом компьютере в момент ввода мастер-пароля.

## Вопросы

**Забыл мастер-пароль.** Восстановить нельзя — у файла нет «чёрного хода». Храните резервную копию файла и помните пароль.

**Где лежит файл?** По умолчанию `%APPDATA%\ru.promptovik.klyuchnitsa\vault.klv`; на экране разблокировки можно выбрать любое место, например флешку.

**Как перенести на другой компьютер?** Скопируйте файл `*.klv` и откройте его в Ключнице на новом ПК.

**Как выгрузить CSV из браузера?** Пошаговые подсказки для каждого браузера есть прямо на экране импорта.

**Нашли ошибку?** Напишите в [Issues](../../issues) или на neurocreator24@gmail.com.
